# Conversational AI Frontend

This is a frontend for a conversational AI Agent project, built using React, Tailwind CSS and Vite.

## Features

- Multiple conversation threads
- Typing indicators for the AI
- Follow-up hints for the user
- Real-time conversation history updates
- Integration with a backend API for AI responses

## Setup

1. Clone the repository: `git clone https://github.com/evertte/MSU_chatbot_.git`
2. Install the dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open the app in your browser at `http://localhost:3000`
